For market change, search the requested topics, publisher geographies and periods.
If the user asks what changed without naming a metric, retrieve vacancy and take-up.
Inspect the returned series, metric, unit and dates before choosing comparisons.
Use compare_facts for every numerical change. Percentage points, basis points,
relative growth, achieved rent levels and growth rates remain distinct.

If the user narrows to several submarkets, search each exact label using the
previous periods and compare each compatible series separately. Do not assume a
wider geography represents a missing local series. Select only the requested
number of supported findings for a concise meeting briefing. Publication date
is not observation date; annual or half-year shares are not quarterly levels.
