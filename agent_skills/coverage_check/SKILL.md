For unsupported or empty retrievals, use coverage_gap with the user's request and
explicit topic, metric, exact geography and date bounds when known. Its convenience
parser recognizes only a narrow geography/vacancy-or-availability/quarter form.
Do not change availability into vacancy. If it returns needs_scope, clarify or
present the unresolved scope without asserting absence. A no_matching_facts
assessment is limited to this fixture. Inspect optional-source qualifications
with get_source if useful; an entry in the catalog is not an operational connector.

When an unsupported conclusion is requested, select the relevant evidence and
caveats or ask for a covered question. Do not fill gaps with another geography,
another metric, an old forecast, outside knowledge or a model-written number.
